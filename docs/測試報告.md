## 未驗證項目與已知限制

| 項目 | 現況 | 後續處理 |
| --- | --- | --- |
| 真實郵件伺服器 | 沒有對 Gmail 或公司 SMTP 寄送過，認證與 TLS 設定未驗證 | 填入真實帳號寄一封 |
| Slack | 只有 Mock，沒有實際串接 | 題目不要求，需要時新增一個 `NotificationChannel` |
| 通知可靠性 | 沒有重試，失敗只記 log；程式在發送前當掉，通知就會遺失 | 正式環境用 Outbox pattern 或 Kafka 加重試 |
| 多實例併發 | 防重複付款靠 `synchronized`，只在單一 JVM 有效 | 接資料庫後改用樂觀鎖或分散式鎖 |
| 效能 | 沒有做壓力測試，併發只測過 50 條執行緒 | 有效能需求時再測 |
| Email 格式驗證 | 只檢查是否含 `@` | 上線前加強 |
| VS Code 執行 | 改成 Java 21 後，要先執行 Java: Reload Projects，否則會出現 `Unresolved compilation problem` | 只影響本機 IDE，`mvn clean test` 不受影響 |

已對照原題，模組三只有「發送通知」一項，沒有遺漏需求。
